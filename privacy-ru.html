2. Какие данные мы собираем

Мы собираем минимально необходимые данные для функционирования Приложения, показа рекламы и обработки платежей:

  • Технические данные устройства (модель, версия Android, идентификаторы устройства) для корректной отрисовки графики (Canvas) и стабильной работы.
  • Данные о статусе покупки (Premium-статус) для управления показом рекламы.
  • При оплате через ЮKassa: данные, необходимые для формирования чека (например, email или телефон, если вы их вводите при оплате).

3. Цели обработки данных

  • Обеспечение базового функционала логической игры-пазла.
  • Показ рекламы через партнёрские рекламные сети (для пользователей без Premium-статуса).
  • Исполнение обязательств по оплате услуги отключения рекламы (взаимодействие с платёжным агрегатором).

4. Передача данных третьим лицам

Мы не продаём персональные данные. Данные могут передаваться только:

  • Платёжному агрегатору (ЮKassa) исключительно для обработки транзакций.
  • Рекламным сетям (в обезличенном виде, через стандартные механизмы Android, такие как Advertising ID) для подбора и показа рекламы.
