Политика конфиденциальности

Настоящая Политика конфиденциальности регулирует порядок обработки данных пользователей мобильного приложения «Пасьянс Солитер» (далее – Приложение).

1. Оператор данных

Оператором является Алексей Валерьевич Бакшин, ИНН 502903197683, зарегистрированный в качестве плательщика налога на профессиональный доход (самозанятого) на территории Российской Федерации.

2. Какие данные мы собираем

Приложение не собирает персональные данные пользователей (имя, адрес электронной почты, номер телефона, платёжные реквизиты и т.п.).

Для обеспечения работы Приложения могут автоматически собираться исключительно анонимные технические данные с помощью сторонних сервисов:

  • Технические данные устройства (модель, версия операционной системы, язык) — для корректной отрисовки графики и стабильной работы.
  • Данные об использовании Приложения (количество запусков, игровая статистика) — для аналитики стабильности.
  • IP-адрес в обезличенном виде — для загрузки рекламы и работы аналитики.

3. Цели обработки данных

  • Обеспечение базового функционала логической игры и сохранение прогресса.
  • Показ рекламы через партнёрские рекламные сети (только для пользователей без Premium-статуса).
  • Аналитика стабильности и количества запусков Приложения.

4. Локальное хранение данных

Настройки игры, прогресс, рекорды и статус Premium-функции хранятся исключительно локально на устройстве пользователя (с использованием Android DataStore) и не передаются на внешние серверы разработчика.

5. Сторонние сервисы

Для обеспечения функциональности Приложение использует следующие сторонние SDK, которые имеют собственные политики конфиденциальности:

  • MyTracker — используется для сбора анонимной аналитики о стабильности работы Приложения и количестве запусков. Политика MyTracker.
  • Рекламная сеть Яндекс — используется для показа рекламы. Яндекс может использовать обезличенные данные для подбора релевантных рекламных материалов. Политика Яндекса.
  • RuStore Pay SDK — используется для обработки внутренних покупок (ежемесячная подписка Premium). Все платёжные данные обрабатываются непосредственно магазином RuStore в соответствии с его политикой конфиденциальности.

Мы не передаём персональные данные третьим лицам. Данные могут передаваться только обезличенно — через стандартные механизмы Android для подбора рекламы и аналитики.

6. Права пользователя

Поскольку Приложение не собирает персональные данные, пользователь в любой момент может полностью удалить все данные Приложения, просто удалив его со своего устройства.

Пользователь вправе направить запрос по вопросам обработки данных на электронную почту: alexbac@yandex.ru. Мы обработаем такой запрос в течение 30 дней.
